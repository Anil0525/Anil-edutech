Computer Awareness for Banking Exams 2026

📅 Updated: September 2026⏱ 10 min read✍️ Anil EduTech

Banking exams లో Computer Awareness

IBPS PO/Clerk, SBI PO/Clerk, RBI పరీక్షలలో Computer Aptitude / Knowledge ప్రశ్నలు వస్తాయి (IBPS/SBI PO Mains లో Reasoning & Computer Aptitude విభాగం). ఇవి చాలావరకు ప్రాథమిక స్థాయి ప్రశ్నలు; నిర్దిష్ట టాపిక్స్ సరిగా చదివితే వేగంగా marks వస్తాయి.

1. కంప్యూటర్ తరాలు (Generations)

తరంసాంకేతికత
1వVacuum tubes
2వTransistors
3వIntegrated Circuits (IC)
4వMicroprocessor (VLSI)
5వArtificial Intelligence పై ఆధారిత

2. హార్డ్‌వేర్ ప్రాథమికాలు

  • CPU భాగాలు: ALU (గణిత, తార్కిక ప్రక్రియలు), Control Unit, Registers.
  • Input devices: Keyboard, Mouse, Scanner, Microphone. Output devices: Monitor, Printer, Speaker.
  • Banking సంబంధిత: MICR — చెక్కులపై అక్షరాల గుర్తింపు; OMR — mark-sense పత్రాల గుర్తింపు.

3. మెమరీ

రకంలక్షణం
RAMVolatile — పవర్ ఆగితే డేటా పోతుంది; తాత్కాలిక నిల్వ
ROMNon-volatile — శాశ్వతంగా నిల్వ; boot సూచనలు
Cacheఅత్యంత వేగవంతమైన చిన్న మెమరీ; CPU కి దగ్గరగా

కొలమానాలు: 1 Byte = 8 bits; 1 KB = 1024 Bytes; 1 MB = 1024 KB; 1 GB = 1024 MB; 1 TB = 1024 GB.

4. సంఖ్యా వ్యవస్థలు

Binary (ఆధారం 2), Octal (8), Decimal (10), Hexadecimal (16). ఉదాహరణ: దశాంశ సంఖ్య 13 = 8 + 4 + 1 = Binary 1101.

5. సాఫ్ట్‌వేర్

  • System software: Operating System (Windows, Linux, Android), Utility programs, Device drivers.
  • Application software: MS Word, Excel, PowerPoint, browsers.
  • Compiler vs Interpreter: Compiler మొత్తం ప్రోగ్రామ్ ను ఒకేసారి అనువదిస్తుంది; Interpreter లైన్ బై లైన్.

6. MS Office షార్ట్‌కట్లు

షార్ట్‌కట్పని
Ctrl + C / X / VCopy / Cut / Paste
Ctrl + Z / YUndo / Redo
Ctrl + SSave
Ctrl + PPrint

Ctrl + B / I / UBold / Italic / Underline
F12Save As (Word)
F7Spelling & grammar check (Word)
F5Slide show ప్రారంభం (PowerPoint)

Excel ఫంక్షన్లు: =SUM(A1:A5) మొత్తం; =AVERAGE() సగటు; =MAX() / =MIN() గరిష్ట / కనిష్ట విలువ; =COUNT() సంఖ్యల లెక్క; =IF(షరతు, నిజమైతే, తప్పైతే).

7. నెట్‌వర్కింగ్ మరియు ఇంటర్నెట్

  • నెట్‌వర్క్ రకాలు: LAN (చిన్న ప్రాంతం), MAN (నగరం), WAN (విశాల ప్రాంతం).
  • Topologies: Bus, Star, Ring, Mesh.
  • Protocols: HTTP/HTTPS (వెబ్), FTP (ఫైల్ బదిలీ), SMTP (ఈమెయిల్ పంపడం), POP3/IMAP (ఈమెయిల్ స్వీకరించడం), TCP/IP.
  • IP address: నెట్‌వర్క్ లో ప్రతి పరికరానికి ప్రత్యేక చిరునామా. URL: వెబ్ పేజీ చిరునామా.

8. సైబర్ భద్రత

  • Virus: ఇతర ఫైళ్లకు అంటుకుని వ్యాపించే హానికర ప్రోగ్రామ్. Worm: స్వయంగా నెట్‌వర్క్ లో వ్యాపిస్తుంది. Trojan: ఉపయోగకరమైనదిగా కనిపించే హానికర సాఫ్ట్‌వేర్.
  • Phishing: నకిలీ ఈమెయిల్/వెబ్‌సైట్ ద్వారా పాస్‌వర్డ్, OTP, కార్డ్ వివరాలు దొంగిలించడం.
  • Firewall: అనధికార ట్రాఫిక్ ను నియంత్రించే భద్రతా వ్యవస్థ. Antivirus: హానికర ప్రోగ్రామ్ లను గుర్తించి తొలగిస్తుంది.
  • బ్యాంక్ ఎప్పుడూ OTP, PIN, CVV ను ఫోన్/ఈమెయిల్ లో అడగదు — ఇది exams లో మరియు నిజ జీవితంలో ముఖ్యం.

9. బ్యాంకింగ్ టెక్నాలజీ

  • CBS (Core Banking Solution): బ్రాంచ్ లన్నింటినీ కేంద్రీకృత డేటాబేస్ తో అనుసంధానం చేసే వ్యవస్థ.
  • NEFT, RTGS, IMPS, UPI: ఎలక్ట్రానిక్ చెల్లింపు వ్యవస్థలు; UPI ని NPCI నిర్వహిస్తుంది.
  • ATM, POS, Internet/Mobile Banking ప్రాథమిక భావనలు.

చదివే విధానం

  1. మొదటి వారం: హార్డ్‌వేర్, మెమరీ, సంఖ్యా వ్యవస్థలు.
  2. రెండో వారం: MS Office షార్ట్‌కట్లు, Excel ఫంక్షన్లు.
  3. మూడో వారం: నెట్‌వర్కింగ్, సైబర్ భద్రత, బ్యాంకింగ్ టెక్నాలజీ.
  4. ప్రతి mock test లో తప్పు చేసిన ప్రశ్నలను 🧠 Revise notebook లో చేర్చండి.

Practice ప్రశ్నలు (సమాధానాలతో)

  1. Volatile memory ఏది? — RAM
  2. చెక్కుల ప్రాసెసింగ్ కు ఉపయోగించే టెక్నాలజీ? — MICR
  3. 1 KB = ? Bytes — 1024
  4. Undo చేయడానికి షార్ట్‌కట్? — Ctrl + Z
  5. ఈమెయిల్ పంపడానికి ఉపయోగించే protocol? — SMTP
  6. నకిలీ ఈమెయిల్ ద్వారా వివరాలు దొంగిలించే దాడి? — Phishing
  7. దశాంశ సంఖ్య 13 యొక్క Binary రూపం? — 1101
